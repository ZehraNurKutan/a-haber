# a-haber
# Haber Portalı  Bu proje, kullanıcıların haber içeriklerini görüntüleyebilmesini sağlayan web tabanlı bir haber portalıdır.  ## Kullanılan Teknolojiler - HTML - CSS Proje kapsamında haber içeriklerinin düzenli ve kullanıcı dostu bir arayüzden amaçlanmıştır. Web arayüzü geliştirme ve sayfa tasarımı  pratik kazanmak amacıyla hazırlanmıştır.
